# TheBench

Verified lawyers and judges rate each other and rate individual decisions on the merits,
anonymously unless they sign. The public sees the consolidated ratings and reviews. The site also
runs surveys so the ratings reach every lawyer in a jurisdiction, not only the ones who show up.

Status: planned (2026-11-06). The plan is [THEBENCH.md](THEBENCH.md). No code yet.

A WetSpark lab project (public repo), to launch as its own company; "TheBench" is the working name.
